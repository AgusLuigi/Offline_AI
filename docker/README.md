# 🐳 Docker Folder

## 🎯 Zweck / Purpose
Sammelstelle für alle Dockerfiles, Build-Instruktionen und Docker-Hilfsskripte.

## 📥 Erlaubte Inhalte / Allowed Files
- Dockerfile - Streamlit-Bauanleitung
- *.dockerignore - Ausschlusslisten

## 🤖 Regeln für zukünftige KI-Modelle / AI Guidelines
Alle containerbezogenen Modifikationen und Image-Bauanleitungen müssen hier deponiert werden.
