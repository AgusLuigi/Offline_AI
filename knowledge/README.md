# 📖 Knowledge Folder

## 🎯 Zweck / Purpose
Ablage von strukturierten Datenbanken und Referenzvorgaben für Qualitätsstandards.

## 📥 Erlaubte Inhalte / Allowed Files
- *.db, *.sqlite - SQLite-Datenbanken
- *.sql - SQL-Schemadateien

## 🤖 Regeln für zukünftige KI-Modelle / AI Guidelines
Bevor die KI ein neues Feature entwirft, MUSS sie in knowledge/app_standards.db die Mindestspezifikationen abfragen.
