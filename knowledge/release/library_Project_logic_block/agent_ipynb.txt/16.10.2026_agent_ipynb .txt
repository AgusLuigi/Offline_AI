[3] VISUELLE TERMINAL-KOMPONENTE: RESOURCE-AWARE SPINNER

Der `ResourceAwareSpinner` läuft in einem entkoppelten Hintergrund-Thread (`threading.Thread`) und begleitet jeden 
Ollama-API-Aufruf (`/api/tags` oder `/api/generate`) mit einer animierten Braille-Punkt-Sequenz und Live-Systemmetriken:

  * Animations-Zeichen: ['⠋', '⠙', '⠹', '⠸', '⠼', '⠴', '⠦', '⠧', '⠇', '⠏']
  * Intervall: Taktung alle 1.0 Sekunde (`SPINNER_INTERVAL = 1`)
  * Live-Überwachung via `psutil`:
      - RAM-Prüfung: Fällt der freie Arbeitsspeicher unter das Limit (`MIN_RAM_MB = 2000` MB), wird automatisch der 
        Python Garbage Collector (`gc.collect()`) ausgelöst und die Warnung `⚠️ RAM kritisch (...) | GC aktiv` angezeigt.
      - CPU-Prüfung: Überschreitet die Last den Grenzwert (`MAX_CPU_THRESHOLD = 90.0` %), erscheint die Warnung 
        `🔥 CPU Last hoch (...)`.
      - Normalbetrieb: Zeigt kontinuierlich den Status `RAM frei: X.XGB | CPU: XX%`.
  * Ausgabesteuerung: Nutzt Carriage Return (`\r`) und `sys.stdout.flush()`, um die Zeile dynamisch im Terminal zu 
    aktualisieren, und säubert das Terminal nach Beendigung des Threads rückstandslos.

[4] GEPLANTE ERWEITERUNGEN (ANGELEHNT AN ENTERPRISE- & DELOITTE-FRAMEWORKS)

Um den Agenten von einem lokalen Skript zu einem vollständig qualifizierten Enterprise-System auszubauen, sind 
folgende Module konzeptionell vorbereitet und für zukünftige Iterationen vorgesehen:

 1. Web Search & Fetch (Live-Recherche):
    - Integration von DuckDuckGo- oder API-Suchwerkzeugen, damit der Agent bei Bedarf aktuelle Bibliotheks-Dokumentationen 
      und Paket-Updates aus dem Internet abrufen kann.
 2. Interaktive REPL & Modulares Tool-System:
    - Übergang vom reinen Batch-Durchlauf zu einer dauerhaften Read-Eval-Print-Loop (REPL) für zielgerichtete, 
      interaktive Terminal-Abfragen.
 3. Session Resume & Checkpoints (Persistenz-Layer):
    - Aktive Nutzung der Datei `.agent_state.json` (Event Sourcing Ledger), um unterbrochene oder abgebrochene 
      Analysen nach einem Systemabsturz oder Stromausfall nahtlos an exakt derselben Zelle fortzusetzen.
 4. Erweiterte Agenten-Evaluation (RAG Triad & LLM-as-a-Judge):
    - Implementierung automatisierter Qualitätsprüfungen für generierte Dokumentationen (Prüfung auf *Context Relevance*, 
      *Groundedness / Faithfulness* und *Answer Relevance*).
