# 📝 Logs Folder

## 🎯 Zweck / Purpose
Zentrale Protokollierung aller Systemereignisse, Startvorgänge, Fehler und Tracebacks.

## 📥 Erlaubte Inhalte / Allowed Files
- *.log - app.log
- Gepackte Log-Archive

## 🤖 Regeln für zukünftige KI-Modelle / AI Guidelines
Die KI nutzt diese Logs im Offline-Modus, um Fehler zu lokalisieren und automatische Korrekturschleifen (Self-Healing) einzuleiten.
