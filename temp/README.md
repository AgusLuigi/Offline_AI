# ⚡ Temp Folder

## 🎯 Zweck / Purpose
Ablage für flüchtige Daten, temporäre Rechenschritte und asynchrone Kommunikationsprotokolle.

## 📥 Erlaubte Inhalte / Allowed Files
- Temporäre Screenshots (current_screen.png)
- JSON-Besprechungsprotokolle
- Intermediäre Trainingsdaten

## 🤖 Regeln für zukünftige KI-Modelle / AI Guidelines
Dieser Ordner darf jederzeit geleert werden. Nutzen zur Entlastung des RAM bei rechenintensiven Multimodalläufen.
