# ⚙️ Config Folder

## 🎯 Zweck / Purpose
Zentrale Speicherung aller Konfigurationsdateien, globalen Einstellungen und KI-System-Prompts.

## 📥 Erlaubte Inhalte / Allowed Files
- *.json - active_model.json, jarvis_config.json, project_paths.json
- *.env - Umgebungsvariablen

## 🤖 Regeln für zukünftige KI-Modelle / AI Guidelines
KIs MÜSSEN diesen Ordner als 'Single Source of Truth' für globale Pfade und System-Prompts betrachten.
