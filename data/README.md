# 📂 Data Folder

## 🎯 Zweck / Purpose
Ablageort für die isolierten Arbeitsbereiche (Workspaces) der einzelnen angemeldeten Benutzer.

## 📥 Erlaubte Inhalte / Allowed Files
- Unterordner pro Benutzer (z.B. data/users/username/workspace)
- Benutzer-Uploads, Dokumente, Bilder

## 🤖 Regeln für zukünftige KI-Modelle / AI Guidelines
Ausbruchsschutz: KIs dürfen niemals aus dem data/-Verzeichnis eines Nutzers in das eines anderen wechseln.
