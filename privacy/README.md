# 🔒 Privacy Folder

## 🎯 Zweck / Purpose
Sicherung sensibler Benutzerdaten durch lokale Anonymisierung direkt auf dem Client-Gerät.

## 📥 Erlaubte Inhalte / Allowed Files
- Schlüssel, Übersetzungs-Tabellen (Name_1 -> Realer Name)
- Regex-Muster für IBAN, Steuernummern

## 🤖 Regeln für zukünftige KI-Modelle / AI Guidelines
Keine unverschlüsselten, sensiblen Daten dürfen diesen Ordner verlassen. Lokale Maskierung vor Web-Anfragen.
